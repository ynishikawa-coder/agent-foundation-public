# 核と道具の届け方

土台の核・skill・hook は、使う側の repo へ写さず、**土台の plugin を窓の起動前に入れて**届けます。正本はこの repo の 1 か所だけです。

## 何がどう届くか

| 物 | 正本 | 窓に届く道 |
|---|---|---|
| 核（常に読む原則） | `plugins/core/核.md` | plugin `core` の SessionStart の hook（`scripts/kaku.py inject`）が起動時に文脈へ差し込む |
| 細目（形に迷った時に読む） | `plugins/core/細目.md` | 差し込みの末尾に、入った plugin の中の path を知らせる（要る時に Read） |
| skill | `plugins/<名>/skills/<skill>/` | plugin として入る（呼び名は `<plugin>:<skill>`） |
| hook | `plugins/<名>/hooks/hooks.json` | plugin として入る |

plugin は入れた時に自分の dir しか持って来ないため、核も `plugins/core/` の中に置きます。

## 使う側がやる事

1. **起動前に入れる**: クラウドの環境の setup script（Mac は手で 1 回か、定期の同期）で、版（tag）を決めて user scope に入れる。

   ```bash
   claude plugin marketplace add ynishikawa-coder/agent-foundation-public#v0.2.0 --scope user || true
   claude plugin install core@agent-foundation --scope user || true
   claude plugin install guard@agent-foundation --scope user || true
   # 使う物だけ: docs-kit・dev-flow・session-watch・checker（どの行も || true を付ける）
   ```

   この repo は public なので、どの環境・どの窓（AI が立てた子の窓も）でも鍵なしで取れます。

   **入れ損ねを黙らせない**: setup script が非 0 で抜けると窓が起動しないので、上の行には `|| true` を付けて失敗しても先へ進めます。その代わり、入れ損ねると核も守りの hook も黙って抜けます。入れた後に次を足し、抜けていれば窓が起動時に必ず読む `~/.claude/CLAUDE.md` に知らせを書きます（全部入れば知らせを消します）。

   ```bash
   want="core guard"   # 入れた plugin の名を並べる
   list="$(claude plugin list 2>/dev/null || true)"; lack=""
   for p in $want; do printf '%s' "$list" | grep -q "${p}@agent-foundation" || lack="$lack $p"; done
   mkdir -p ~/.claude && touch ~/.claude/CLAUDE.md || true
   sed -i '/^<!-- af-plugin-missing -->/d' ~/.claude/CLAUDE.md || true
   [ -n "$lack" ] && echo "<!-- af-plugin-missing --> 土台の plugin が入っていない:$lack。核と守りの hook がこの窓で効いていない。最初にオーナーへ知らせる。" >> ~/.claude/CLAUDE.md || true
   ```

   Mac には起動前の setup script が無いので、上の 2 つ（入れる・確かめる）を手で 1 回打ち、版を上げる時も手で打ち直します。
2. **`CLAUDE.md` には、その repo に固有の決まりだけを書く**。核の写しの枠（`<!-- AF-CORE:BEGIN … -->`）は置かない。量の上限は `python3 plugins/core/scripts/kaku.py check --claude <その repo の CLAUDE.md>` で照らせる（数は `kaku.py` の `LIMITS`）。
3. **版を上げる時は、使う側の版の 1 行（tag）だけを直す**。

## 移る間（写しの枠がまだ在る repo）

開いた repo の根の `CLAUDE.md` に写しの枠が在る時、plugin `core` は核を差し込みません（核が二重に入らないため）。枠を畳むと、次の起動から差し込みが効きます。枠を畳む PR と、plugin `core` を入れる setup script の直しは同じ頃に入れます。

## 確かめ方

新しく立てた窓で `claude plugin list` を打ち、入れた plugin が全部 enabled で出るか、起動時の文脈に核（`# 振る舞いの核（agent-foundation）`）が在るかを見る。
