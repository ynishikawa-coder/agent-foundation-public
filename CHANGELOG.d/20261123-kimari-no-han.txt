- 壊れる: plugin checker のレビューは、始めた時の決まりで見る。判定の 3 行目に `決まりの版: <土台の commit の SHA 先頭 12 文字>` が要り、`verdict_form.py` は `--first <この PR の初めの判定の決まりの版|なし>` が無いと exit 2。初めの判定は main の先端の版で書き、2 回目からは初めの判定と同じ版で書く。見る点・選べる値・札はその版の review-pr の SKILL.md から読む（決まりの git は環境変数 AF_RULES_GIT、無ければ ~/.claude/plugins/marketplaces/agent-foundation）。途中で main に足された見る点で red を返し合わない。ただし `- 版によらず当てる点:` の点（今は 5 秘密・顧客の物）は main の先端の名と値で必ず見る。版が読めない時は照らさずに exit 2。`review_gate.py` は入ってよい時に従う版と `--first` の値を出し、guard の pr_text は判定を出す前に PR の初めの判定の版で照らす。
- 直した: `scripts/pr_overlap.py` の重なりの知らせは、順（先に開いた PR が先に入り、後の PR は入った main を取り込んで続ける＝AI が決める）と、オーナーに聞く時（片方がもう片方の通る条件を変える・2 つの意図が逆向き）だけを言う（オーナーの答え 2026-11-23）。
