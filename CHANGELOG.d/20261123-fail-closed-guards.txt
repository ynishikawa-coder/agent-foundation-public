- 壊れる: 守りの hook（guard）は、見張りの例外・HOOKS の宣言が読めない・入力の JSON が読めない時に、PreToolUse で止める（今までは黙って通した）。PostToolUse・SessionStart は壊れた見張りの名を隣に知らせるだけ。

- 直した: 守りの hook が照らす repo の根は、入力の cwd の作業の木の根を正本にする（後から clone した別の repo で働く窓で、窓を立てた dir の表を読まない）。
- 直した: PR の文の照らし・重なりの照らし（pr_overlap）・レビューの関所（review_gate）は、取れない応答・途中までの頁・読めない差分を「無い」とせず止める側に倒す。review_gate は同じ名の check run を check suite ごとに分けて新しい物を取る。
