- 壊れる（1 段目）: PR の型の頭の `書いた窓:` の欄を畳んだ（手で書く写しで、push の後でしか直せず、別の窓が main を取り込んで push する度に先端の commit の窓とずれ、その push の CI が毎回 1 回赤になった）。書いた窓は PR の commit 全部の `Claude-Session:` の窓の組（記録）だけから読む。使う側の `.github/pull_request_template.md` に残る `書いた窓:` の行は古い形 `pr-writer-field` として起動の hook が名指すので、その repo の窓が消す。古い本文は守りの hook がまだ通す（2 段目で頭の塊の `書いた窓:` も窓の id として数える）。
- 壊れる: plugin checker の pr_writer.py は `--body-file` を受けない。CI の照らしは「claude/ の枝の PR の commit に `Claude-Session:` が 1 つも無ければ赤」だけで、本文と照らさない。守りの hook（guard の pr_text）は判定の材料の書いた窓の組に本文の `書いた窓:` を足さない。取り込みの merge commit を書いた窓は、これまでどおり書いた窓の組に入る（別の目になれない）。
