- 壊れる（1 段目）: 書いた窓は PR の commit 全部の `Claude-Session:` の窓の組（記録）だけから読む。PR 本文の頭の `書いた窓:` は CI も今の道具も読まず照らさない（前の形は本文を先端の commit の窓と照らし、本文は push の後でしか直せないので、別の窓が main を取り込んで push する度にその push の CI が 1 回赤になった）。PR の型の `書いた窓:` の行は、古い土台で立った窓の守りの hook が判定の材料に本文を読むので 2 段目まで残す（main の取り込みの後に直さなくてよい）。2 段目で PR の型から行を消す。
- 壊れる: plugin checker の pr_writer.py は `--body-file` を受けない。CI の照らしは「claude/ の枝の PR の commit に `Claude-Session:` が 1 つも無ければ赤」だけで、本文と照らさない。守りの hook（guard の pr_text）は判定の材料の書いた窓の組に本文の `書いた窓:` を足さない。取り込みの merge commit を書いた窓は、これまでどおり書いた窓の組に入る（別の目になれない）。
