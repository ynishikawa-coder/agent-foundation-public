- 壊れる: guard に守り `pr_text` を足した（オーナー同意 2026-11-19）。GitHub の道具で PR の題・本文とコメントを出す前に照らし、崩れていれば AI だけを止める（人の操作は止めない）。レビューの判定のコメントは checker の `verdict_form.py` を直に呼んで形を見る。PR の本文は dev-flow の preimpl-cleanup の `整地受領証.template.md` の 4 つの見出しを直に読み、欠けか雛形の `〔…〕` の残りで止める（整地の要らない PR は本文に `整地: 不要（<訳>）` の 1 行）。PR の題・本文に窓の id がそのまま在れば止める（頭の決まった欄・コード・URL の中は数えない）。公開の repo（窓の repo の取り出しの workflow が action `public-guard` を呼ぶ・値の表 `guard.public_repos_extra`）へは、題・本文・コメントと MCP から出す commit の説明（merge・push_files 等）を `public-guard/guard.py --text`（新しい口: 出す前の文だけを同じ表で照らす）に渡し、当たれば止める。判定の道具・雛形・公開の検査が見つからない・壊れた時も止める。外す口は `guard.pr_cleanup_exempt_repos`・`guard.pr_words_exempt_repos`（判定の形と公開の検査は外さない）。使う側: 整地を PR 本文に書かない repo は値の表で外す。
