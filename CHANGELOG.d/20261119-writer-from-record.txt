- 壊れる: 判定のコメントを出す時、守りの hook（guard の pr_text）が判定した窓を 1 行目の名乗りの字でなく出す窓の環境の記録（CLAUDE_CODE_REMOTE_SESSION_ID）から取り、名乗りの字が違えば止める。記録の無い窓（手元の CLI）からは判定を出せない
- 壊れる: 書いた窓を PR の commit 全部の Claude-Session: の窓の組から取る（途中の commit を書いた窓も書いた側）。commit に記録が無い PR へは判定を出せない（本文の 書いた窓: の写しだけで決めない）
- 足した: verdict_form.py の --reviewer（判定を出す窓の本物の id）と、--writer の `,` で並べた組。scripts/pr_writer.py --writers（PR の書いた窓の組を出す）
- 直した: 子の窓（文脈の知らせ・題の印）を、頼みの文の親窓・返し先の写しだけで決めず、頼みの行の記録（人が打った頼みでない）と合う時だけ数える。オーナーが引き継ぎの文を貼った窓は子の窓にしない
