# 試験で守らない文

核・振る舞いの既定・細目の文のうち、消しても試験が赤にならない文（`tests/test_rule_holes.py` が照らす）。

- 1 件 1 file。名は `<中身の sha1 の頭 12 字>.txt`、中身は 1 行 `<path><TAB><文>`（名と中身が合わなければ赤）。全部の PR が同じ 1 枚の末尾へ行を足すと、1 本入るたびに残りの PR が衝突するので、行を同じ file に集めない（`CHANGELOG.d` と同じ形）。
- 新しい文はここへ足さず、文を照らす試験を足す。試験で守られた文・無くなった文は file ごと消す。
- この表の残りは原因の台帳の行（核と細目の文の試験の穴）が持つ。
