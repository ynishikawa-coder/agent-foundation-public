# 値の鍵の当て方（guard）

字・正規表現の鍵の当て方（何に・全体か一部か）の正本は型の正本 `skill-values/schema.json` の鍵の spec（`against`＝当てる相手・`match`＝`whole` は相手の全体・`part` は相手の一部）。道具は値の表の口（`skill_values.py` の `compile_patterns`・`hit`・`words_in`）だけで当てる。全体に当てる鍵（各行を `^` で始め `$` で終える）: `irreversible_tools_extra`（道具の名）・`qa_page_exempt`（問いのページの file の path を repo の根から `/` 区切りで。repo の上の dir の名には当たらない）・`ask_term_allow`（中の言葉と見つけた字の塊）・`outbound_secret_allow`（鍵の形に当たった字の塊）・`ask_prior_lookup`（道具の呼び出し 1 つ＝道具の名・空白 1 つ・入力の JSON〔鍵の順に並べた 1 行・区切りは「, 」と「: 」〕。道具の名から書くので、Bash の echo や別の道具の入力に語が在っても当たらない）。`^…$` でない行は前の形（一部に当てる読み方）で、今は前の読み方のまま効かせて値の表の照らしが名指す（起動の知らせ・`values_keys.py`）。一部に当てる鍵: `irreversible_bash_extra`（Bash の命令の全文）・`ask_inner_terms_extra`（問いの文・返事の本文）・`ask_shape_exempt`・`ask_pick_one_exempt`・`ask_rec_notice_exempt`・`ask_prior_exempt`（問いの文）・`number_request_exempt`（外へ送る文の 1 文）。`paid_markers_extra` は字のまま一部に当てる（型 `words`・正規表現でない。`\` を含む行は正規表現のつもりの書き違いとして名指す）。
