# pick_one（1 つだけ選ばせる問い）

- 出来事: PreToolUse
- する事: 選択肢の画面（AskUserQuestion）で、1 つだけ選ぶ問い（multiSelect が偽）の文が、これからやる物・手を付ける順を選ばせる意志の形（どれを進めますか・何から始めますか・どの論点を先に詰めますか・どれを優先しますか）か、原因の見立てを選ばせる形（原因はどれだと思いますか・どれが原因に近いですか）なら止める。全部を選べる問い・選択肢に全部やる道（全部・すべて・両方・同時・並行）が在る問いは通す。過去（〜しましたか）・受け身（〜されますか）・「が」を挟む形・意味や事実の問い（どちらの意味ですか・原因はどの資料に書いてありますか）は当てない。画面はまだ人に出ていない＝止まるのは AI の問いだけ

## 止められた・知らされた時の直し方

相談で出た事は全部やる（オーナー決定 2026-11-19）。①聞くならやり方を問う（「全部この窓で順に」「それぞれ別の窓で同時に」）②全部を選べる形にする（multiSelect か「全部」）③原因は AI が全体の絵の上で見立てて示し、合っているかを問う ④調べれば決まる順は問わずに AI が決めて全部進める。推奨の印は作り方の分かれ道の問いだけ（細目 §4「推奨の印」）で、やり方・全部やるかを問う選択肢には付けない。誤って止まった（意図・事実・意味の問い）時は問いの文を「どちらが正しいか／どの意味か／どちらにするか」の形に直して出し直し、同じ形で何度も止まるなら値の表の `ask_pick_one_exempt` に足す（PR とレビューを通す）

## 値の表の鍵

repo の根の `config/skill-values.json` の `"guard"` に書く（鍵・型・既定・当て方〔`against`＝当てる相手・`match`＝`whole` は相手の全体・`part` は相手の一部〕の正本は土台の `skill-values/schema.json`）。

```json
{
  "guard": {
    "ask_pick_one_exempt": ["^作り物の試しの順"]
  }
}
```

## 射程の外

- 1 つだけ選ばせる問いの見張りは、問いの文の語の形による推し量り（意味は読まない）。「AとBのどちらにしますか」のように作業の名を選択肢にだけ並べ、問いの文に進める・優先・原因の語が無い形は素通りする。言い換えでも抜けられる（残る穴・別の目のレビューと手で回す点検で拾う）。
