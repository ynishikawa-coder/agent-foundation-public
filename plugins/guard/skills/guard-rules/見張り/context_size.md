# context_size（文脈の量）

- 出来事: PostToolUse
- する事: 文脈が目安を越えた最初の 1 回だけ知らせる

## 止められた・知らされた時の直し方

人のいる窓は区切りで引き継ぎを書き後継の窓へ替える。人のいない窓は今の段を終えて引き継ぎを書き止まる

## 値の表の鍵

repo の根の `config/skill-values.json` の `"guard"` に書く（既定はこの見張りの file の頭の `VALUES`）。

```json
{
  "guard": {
    "context_limit": 300000
  }
}
```

## 射程の外

- 書くほどの穴は見つかっていない（見つけたら原因の台帳に行を足し、ここに書く）。
