# unanswered（未回答の台帳）

- 出来事: PostToolUse・SessionStart
- する事: モーダルが答えのないまま閉じた問いを台帳に積み、24 時間の間、次の窓の冒頭に全部を渡す（頭の何件かで切らない）。寿命を過ぎた問いと文面の無い行は冒頭で一度知らせてから降ろす（控えは expired_recent）。人のいない窓では知らせず控えへ移すだけで、次の人のいる窓が一度知らせる。`list` は寿命切れ・文面の無い行・控えへ移した行に印を付ける。答えが返れば降ろす（同じ問いの見分けは文面の一致か含有だけ。字の形で別の問いを結ばない）。子の窓の問いも同じ

## 止められた・知らされた時の直し方

1 件ずつ、今の窓の流れで扱う: ①答え済み・もう要らない → 出さずに `python3 <unanswered.py> drop <key> --why <訳>` で降ろす（渡された文に path が出る・`list` で一覧）②今の頼みと関わる → チャットで前提を 1〜2 文添えてから出し直す（問いの文は短く言い直してよい。言い直した問いに答えが返ったら、元の問いを drop で降ろす＝機械は結ばない）③関わらない → 冒頭で画面に出さず、締めの「あなたがやること」に 1 行で知らせ、求められたら出す。出す問いが 4 を越えたら 4 問ずつ続けて出す。言い方だけ変えて何度も出さない

## 値の表の鍵

この見張りだけが読む鍵は無い（皆の鍵 `unattended_env`・`state_dir` は SKILL.md）。

## 射程の外

- 未回答の台帳の扱い（降ろす・前提を添えて出す・締めで知らせる）は AI の判断で、答え済みかを機械は確かめない。降ろした問いは台帳の `dropped_recent` に訳と一緒に残る。
