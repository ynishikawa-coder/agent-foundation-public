# prior_ask（聞く前に引いた跡）

- 出来事: PreToolUse
- する事: AskUserQuestion の画面が人に出る前に、会話ログの最後の頼み（人か親の窓が打った行）より後に、決定の記録と問いの表を引いた跡（値の表 `ask_prior_lookup` の正規表現に「道具の名 + 入力の JSON」が当たる道具の呼び出し）があるかを見る。無ければ AI だけを止める（同じ頼みの中で 2 回まで・越えたら通す）。`ask_prior_lookup` が無い repo は引いたかを見分けられないので、窓ごとに 1 回だけ止める

## 止められた・知らされた時の直し方

細目 §4 の「聞く前に引く」をして、答え済み・資料で決まる・道具の都合の問いを外し、引いた結果を問いの前にチャットで 1 行書いて出し直す。引けない時は 2 回止まった後に通るので、引けなかった事を問いの前に書く。引いたのに止まった時は使った道具の形を `ask_prior_lookup` に、引く要の無い問い（手の作業が済んだかの確かめ等）は `ask_prior_exempt` に足す（PR とレビューを通す）

## 値の表の鍵

repo の根の `config/skill-values.json` の `"guard"` に書く（既定はこの見張りの file の頭の `VALUES`）。

```json
{
  "guard": {
    "ask_prior_lookup": ["notion-(?:search|fetch|query-data-sources).*決定", "\\bGrep\\b.*問いの表"],
    "ask_prior_exempt": ["終わりましたか|済みましたか"]
  }
}
```

## 射程の外

- 聞く前に引いた跡の見張りは、引く道具を呼んだかだけを見る（何を引いたか・問いと同じ言葉で引いたか・答え済みの問いを外したかは見ない）。引く先は会社ごとに違うので値の表に書く（`ask_prior_lookup` の例の道具の名は作り物）。値の無い repo では窓ごとに 1 回止めるだけ。
