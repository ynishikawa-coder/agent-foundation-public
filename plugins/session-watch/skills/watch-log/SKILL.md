# 会話ログの点検

点検は会話ログだけを読む（環境の値・外の台帳・`get_session` の返りを見ない）。手で回す: `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/session_watch.py" <transcript.jsonl>`。拾った物を 1 行ずつ出し、拾えば exit 1（最後の行で細目 §3「まず構造を疑う」 を指す）。知らない印・読めないログ・照らしの故障は exit 2 で止まる（拾う物なしの緑に化けない）。会話ログの番（ターン）は人が打った行だけで切る（正本は plugin guard の `guard_common.starts_turn`＝別の窓・仕組みの知らせの行と要約の行は番を切らない）。拾われた物は下の直し方で出し直すだけで済ませず、返事の形が守る意図とのずれから入り、細目 §3「まず構造を疑う」で原因を探して直す。

`title`（今の題で直せる物）・`card`・`close`・`plain`・`inner`・`time`・`done`・`holes`・`secret`・`neighbor`・`unread`・`nolog` は、Stop の hook（`session_watch.py --stop`）も同じ見張りで見て、崩れていれば次の頼みの時に UserPromptSubmit の hook（`--remind`）が隣へ知らせる（差し戻さない＝`decision: block` を出さない・返事はそのまま届き書き直さない・次の返事から合わせる）。知らせの文に直し方と誤った時の外し方を出す。誤って当たる行は値の表 `config/skill-values.json` の `session-watch.watch-log.reply_exempt`（行に当てる正規表現の並び・`inner`・`time`・`done` で見ない）に、中の言葉の字は `guard.ask_term_allow` に足す（PR とレビューを通す）。「問いを出す前に ❓ を付けていない」は過ぎた事で今は直せないので知らせない。ほかの札（`idk`・`unanswered`・`rest`・`hand`）は手で回す点検と知らせるだけ。`neighbor`・`unread`・`nolog` は AI には直せないので窓ごとに 1 回だけ知らせる。hook の口で照らしそのものが壊れた時も、窓は止めずに窓ごとに 1 回だけ壊れたと知らせる（黙って「崩れなし」にしない）。

## 拾う物と直し方

| 札 | 拾う時 | 直し方 |
|---|---|---|
| `rest` | 締めの `AI がこの後やること` が「なし」でないのに、その窓で残りを動かす手（`create_session`・`send_message`・`send_later`・`subscribe_pr_activity`・背で走らせた `Agent`・`Workflow` 等）を一度も打っていない（題が ❓／💤 の待ちの窓・✋ の手の窓と、既に子窓・見張りを動かした窓は除く） | 子窓や背で走る助手に頼む・PR を見張る・後で起こすのどれかを打ってから締める（核「返事の形」） |
| `title` | 題の頭に種類が無い／種類の後に状態の表に無い印がある・表に無い組み合わせ（✋ に ❓・💤・🛑）・作業名の頭の古い `手:`（表の正本は `session_watch.py` の `TITLE_TABLE`・skill `title-mark`）／種類が返し先と違う／問いの前に ❓ が無い（✋ の窓は除く）／答えが返ったのに ❓ が残る／🤖・✋ の窓が `✅終わった` で報告するのに題が ✅ でない・終わった でない札（🛑止まった・一部など）で締めるのに題が ✅／手の窓（`✋ <何を>`）が `✅終わった` で締めるのに、その窓で頼んだ窓へ返した跡（`send_message`）が一度も無い。問いと同じ返事（同じ message）で付けた題は問いの前に付けたと見る | `title-mark` の skill の形に `set_session_title` で付け替える。手の窓は済んだ目印を頼んだ窓へ返してから締め、自分を閉じる（細目「聞き方」・細目「返事の形」） |
| `close` | 一言で済む返事（札も締めも無く 3 行以下・問いを出していない）の外で、最後の 2 行が `AI がこの後やること: …` と `あなたがやること: …` でない | 締めの 2 行（核「返事の形」）で書き直す |
| `card` | 一言で済む返事（札も締めも無く 3 行以下・問いを出していない）の外で、返事の 1 行目が 4 札（核・絵と語の組。`🛑止めた`・`❓🟢` のように絵だけ合う物も拾う）で始まらない | 1 行目を ✅終わった／❓答えて／💤待ち／🛑止まった のどれかで始める（前の砂時計の待ちの札は畳んだ） |
| `plain` | このターンに選択肢の画面が無いのに、答えを求める問いで締め、「AI の今の読み」も添えていない | 選ぶ問い（分かれ道・やってよいか・済んだか）なら、行頭が「具体例:」「判断の物差し:」の 2 行をチャットに出してから選択肢の画面で聞く（「分からない」も置く・推奨の印は作り方の分かれ道だけ）。開いた問い（意味・考え・前提）ならチャットのまま「AI の今の読み」を添える。調べれば決まる事なら AI が決めて進む（細目「聞き方」） |
| `idk` | 選択肢の画面の問いに「分からない」の選択肢が無い | 「分からない」（選ぶと AI が聞き方を変えて聞き直す）を足して出す（細目「聞き方」） |
| `unanswered` | 選択肢の画面で出した問いに答えが返っていない（その画面か後に出し直した画面に答えが返った・人が画面を閉じてから打った行がある時は答えたと見る。知らせの行は答えに数えない） | 今の流れで前提を 1〜2 文と「具体例:」「判断の物差し:」の 2 行を添えて出し直す（選択肢の見出しは変えない）か、答え済み・要らないなら台帳から降ろす（skill `guard:guard-rules`）。答えが要らない作業は進める |
| `hand` | 手の窓（`✋ <何を>`）の返事に、目的・手順・済んだ目印・済んだ後のどれかが無い／手の窓でない窓が、締めの「あなたがやること」に人の手の手順（番号付きの手順・コードブロック・→ の並び・開く／貼る／足す／押す 等の手が 2 つ以上）を直に書き、手の窓の URL（`claude.ai/code/session_…`）が無い（「なし」・URL だけ・問いに答えるだけは拾わない） | 手の窓は 4 つを書き切る（手順は貼る文を全部）。頼んだ窓は人の手を手の窓（1 つの頼みに 1 つの窓）で頼み、「あなたがやること」には手の窓の URL だけを書く（細目「聞き方」）。クラウドの窓では、次の頼みの時に UserPromptSubmit の hook も同じ事を隣に知らせる（止めない） |


返事の中身の札（Stop の hook も見て次の頼みの時に知らせる）:

| 札 | 拾う時 | 直し方 |
|---|---|---|
| `inner` | 人への返事の本文（コードの囲み・`` ` `` で囲んだ字・URL を外した所）に、AI の中の言葉らしい字（`Q202611-67`・`E02` の形の番号・`#616`・窓の id・`直し_0020` の形の名・commit の印）がある。見分けの正本は plugin guard の `ask_shape.inner_terms`（選択肢の画面と同じ物を直に呼ぶ・写さない）。file 名・path・版・英字の識別子は数えない（核「日本語」コード・パス・固有名は英語でよい）。返し先が別の窓の窓（🤖）は人への文でないので見ない | それが何かを日常の言葉で言い換える（PR は URL で渡す）。 |
| `time` | 時刻（`HH:MM`・`17時53分`）に `Z`・`UTC`・`GMT`・`+09:00` 以外の時差が付く／日付の付いた時刻の句に日本時間の印（日本時間・JST・+09:00）が無い（印は時刻と同じ句〔、。で切る〕の中か、時刻を持たない句〔「〜まで、日本時間で。」〕に在れば通す。時刻を持つ別の句の印は掛けない）。コードの囲みの中は見ない | `YYYY-MM-DD HH:MM 日本時間` で書く（核「時刻は日本時間」）。記録をそのまま見せる時はコードの囲みに入れる |
| `done` | 1 行目が ✅ の返事で、終わりの語（終わった・済んだ・直った・できた・通った・緑 等）と同じ文に、言い切らない語（ほぼ・大体・たぶん・はず・おそらく・と思う・かもしれない）がある。「」で引いた言葉と、先の事の見込みの句（次の・来週・今後・予定 等があり、過去の言い切りの無い句。、で切る）は数えない。2 つの語が「、」をまたいでも同じ文なら数える | 確かめた事だけ言い切る。残りがあれば札を 💤／🛑 にし、何が残るかを書く（核「完了の 4 状態」） |
| `holes` | 1 行目が ✅ の返事に、穴・直す窓・原因の台帳・台帳の行の語が在るのに「どうしますか」「どうするか」が無い | 頼まれた物が終わった事と前→後を先に書き、目標の外の穴ごとに何が穴か／放っておくと何が起きうるか／AI の案を添えて「どうしますか」と聞く（細目 §7「報告の書き方」） |
| `secret` | 返事（コードの囲みの中も）に鍵・トークンの形がある。形の正本は公開の検査 `public-guard/guard.py` の `secret_labels`（直に呼ぶ）。知らせの文には札の名だけを出し、値は出さない | 値を消し、在り処の名だけを書く（核「安全」） |
| `unread` | 会話ログに読めない行（JSON として読めない・dict でない）がある。その行を除いて照らした事を行の番号つきで名指す（黙って飛ばさない） | 書きかけ・壊れた会話ログ。題・問い・答えの判定は手で確かめ、続くなら読み口を直す PR を出す |
| `nolog` | hook の口で会話ログの path（`transcript_path`）か file が無い。空の会話ログとして黙って照らさず、返事の文の形だけ照らした事を名指す（最初の頼みの hook は file がまだ無いことがあるので path だけを見る） | hook の入力の変化・会話ログの置き場の誤り。plugin session-watch の hooks.json と Claude Code の版を確かめる |
| `neighbor` | 上の正本（隣の plugin guard・市場の写しの `public-guard/guard.py`）が見つからず照らせない／照らしが壊れた／値の表の `reply_exempt` に正規表現として読めない形がある（読めない形は捨て、他の札は札ごとに照らし続ける）。探す順は 環境変数（`AF_ASK_SHAPE`・`AF_GUARD_COMMON`・`AF_PUBLIC_GUARD`）→ 同じ repo の隣 → 入れた plugin の同じ版 → 市場の写し → 入れた plugin の新しい版 | 土台の plugin guard を入れ直す（`docs/核の届け方.md`） |

`title` には、クラウドの窓で題が会話ログに一度も無い時（親が `create_session` で付けた題は会話ログの外）も入る。材料が無い時は既定で止め、`get_session` で今の題を読み、skill `title-mark` の表に照らして `set_session_title` で付けさせる（親の題を写さない。表に無い印・組み合わせは直して付ける。崩れた題は付ける口〔guard の outbound〕で止まる）。

## repo ごとの値

値の表は使う repo の根の `config/skill-values.json`（在る時だけ読む・無ければ外す形なしで照らす）。

| 鍵 | 中身 | 既定 |
|---|---|---|
| `reply_exempt` | 返事の行に当てる正規表現の並び。当たる行は `inner`・`time`・`done` で見ない（引いた記録・誤って止まる形だけ。PR とレビューを通す）。読めない形は捨てて `neighbor` で名指す | `[]` |

## 点検の外

- 日本語で書いているか・言い換えがあるかは見ない（言い回しの判断が要る）。
- 平文の問いは型（末尾の ？・❓ 札・問いの言い回し）で拾い、「AI の今の読み」が在れば開いた問いとして拾わない。修辞の問いを拾ったら、そのままでよい。
- 問いの言葉（開発用語・業界の専門用語・決まりの言葉・オーナーの言葉の混ざり方）は見ない（言葉の判断が要る・細目「聞き方」）。
