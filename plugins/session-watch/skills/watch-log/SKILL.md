# 会話ログの点検

点検は会話ログだけを読む（環境の値・外の台帳・`get_session` の返りを見ない）。手で回す: `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/session_watch.py" <transcript.jsonl>`。拾った物を 1 行ずつ出し、拾えば exit 1。hook には載せない（返事を止めない）。

## 拾う物と直し方

| 札 | 拾う時 | 直し方 |
|---|---|---|
| `title` | 題の頭に種類が無い／種類が返し先と違う／🙋 に ✅／問いの前に ❓ が無い／答えが返ったのに ❓ が残る／🤖 の窓が `AI の残り: なし` で締めるのに ✅ でない | `title-mark` の skill の形に `set_session_title` で付け替える |
| `close` | 最後の 2 行が `AI の残り: …` と `オーナーの残り: …` でない | 締めの 2 行（核）で書き直す |
| `card` | 返事の 1 行目が 4 札（核）で始まらない | 1 行目を ✅／❓／⏳／🛑 のどれかで始める |
| `plain` | このターンに選択肢の画面が無いのに、答えを求める問いで締めた | オーナーにしか決められない判断なら選択肢の画面で聞く（推奨を 1 つ目）。調べれば決まる事なら推奨で決めて進む |
| `unanswered` | 選択肢の画面で出した問いに、一度も答えが返っていない | 文面と選択肢をそのまま出し直す。答えが要らない作業は進める |
| `hand` | 手の窓（`🙋⏳ 手: <何を>`）の返事に、目的・手順・済んだ目印・済んだ後のどれかが無い | 4 つを書き切る（手順は貼る文を全部）。頼んだ窓は「オーナーの残り」に手の窓の URL を書くだけ |

## 点検の外

- 日本語で書いているか・言い換えがあるかは見ない（言い回しの判断が要る）。
- 平文の問いは型（末尾の ？・❓ 札・問いの言い回し）で拾う。修辞の問いを拾ったら、そのままでよい。
