# 窓の題の目印

題の形と返事の札・締めの正本は核（plugin `core` が起動時に差し込む `plugins/core/核.md`）。種類×状態の表の正本は見張り（`session_watch.py` の `TITLE_TABLE`）で、下の表はその写しを試験が照らす（オーナーの決定 2026-11-22）。題を付ける口（`set_session_title`）と窓を立てる口（`create_session` の title・手の窓の頼みの 4 欄）は、guard の outbound が出す前に同じ正本（`title_shape`）で照らし、表に無い印・表に無い組み合わせなら AI だけを止める。手で回す点検（skill `watch-log`）と Stop の見張りも同じ物で拾う。

## 種類（1 文字目）

- `🙋`＝オーナーと話す窓／`✋`＝手の窓（オーナーの操作を頼む窓）／`🤖`＝AI が立てて AI に返す窓。この 3 つ以外の印（🟢・🟡・⚪・🔨 など）は付けない。
- 種類の決め方は 2 段: まず手の窓（オーナーの操作を頼む窓）は返し先によらず `✋`。それ以外は窓の最初の頼みの文に書いた返し先だけで決める: `返し先=オーナー` → `🙋`／`返し先=session_…` か `（親窓 session_… の子）` → `🤖`（別の窓を指す返し先は手で書いた写しなので、頼みの行の記録が人の打った物でない時（行がまだ無い最初の知らせでは get_session の `parent_session_id`＝別の窓が立てた記録が在る時）＝別の窓や仕組みから来た頼みの時だけ数える。オーナーが引き継ぎの文を貼った窓は `🤖` にしない）／どれも無い → 窓が自分で決める（点検は種類の食い違いを拾わない）。この文は見張りの正本（`session_watch.py` の `KIND_RULE`・決め方は `window_kind`）と同じ文で、試験が一致を照らす。
- 役（何をする窓か）は作業名に書き、題に役の印は付けない。役の決まった一覧は無い（相談だけ・見張りだけの窓も、そのまま作業名に書く）。手の窓は種類 `✋` で表し、作業名に `手:` を付けない。

## 状態（2 文字目）と付けてよい種類

| 状態 | 意味 | 付けてよい種類 |
|---|---|---|
| 無し | AI が動いている（`✋` はオーナーの操作待ち） | `🙋`・`✋`・`🤖` |
| `❓` | オーナーの答え待ち | `🙋`・`🤖` |
| `💤` | ほかの窓・合流待ち | `🙋`・`🤖` |
| `🛑` | 止まった（外し方は本文） | `🙋`・`🤖` |
| `✅` | 終わった（核 §7）・後継へ渡した | `🙋`・`✋`・`🤖` |

- 表に無い印（`⏳` など）と、表に無い組み合わせ（`✋❓` など）は付けられない。
- `❓` はオーナーへの問い（選択肢の画面か、チャットで聞く開いた問い）を出す前に付け、答えが返ったら外す。子の窓も自分で直に問う。`✋` の窓は `❓` を付けず、済んだかも状態なしのまま聞く。
- `💤` はほかの窓の返事・合流を待つ間。`🛑` は止まった時で、何に当たったか・誰が何をすれば外れるかを本文に書く。
- `✅` は「終わった」（核 §7）か後継へ渡した時。`🤖`・`✋` の窓が `✅終わった` で報告するターンは題を `✅` にする。`🛑止まった`・一部・待ち・問いで締める時は `✅` にしない。`🙋✅` は「AI の手は終わり・閉じるかはオーナー」。
- `✋` の窓は目的・手順（貼る文は全部）・済んだ目印・済んだ後をその窓に書き、済んだら頼んだ窓へ返して `✋✅` にする。
- 返事の 1 行目の札は核の 4 札: `✅終わった`／`❓答えて`／`⏳待ち`／`🛑止まった`（札の `⏳待ち` は題の状態の `💤` と絵が違う。題に `⏳` は付けない）。

## 付け方

- 手の窓を頼んだ窓の「あなたがやること」は手の窓の URL だけ（手順は手の窓へ）。手順を直に書くと、次の頼みの時に同じ hook が知らせる（細目 §4・止めない）。
- 最初の返事の前に付ける。クラウドの窓でまだ種類の印が無い間は、UserPromptSubmit の hook（`session_watch.py --remind`）が頼みのたびに隣へ知らせる（止めない）。返し先が別の窓の子窓には、親が `create_session` の title で付けた題を、この表に照らして付けるよう知らせる（親が付けた題は会話ログに載らず、返事の見張りが照らせない。親の題を写さず、表に無い印は直して付ける）。
- 題の印が崩れたまま返事を締めると、Stop の hook（`session_watch.py --stop`）が見つけ、次の頼みの時に隣へ知らせる（差し戻さない・返事は書き直さない）。クラウドの窓で題が会話ログに一度も無い時も知らせる（`get_session` で今の題を読み、表に照らして `set_session_title` で付け直す）。
- 付け替えは窓自身が `set_session_title` でする（自分の session id と今の題は `get_session` を session_id を省いて読む）。ほかの窓の題を付け直す時も同じ口を通る。題の例: `🤖 <作業名>`・`🤖❓ <作業名>`・`🤖💤 <作業名>`・`🤖✅ <作業名>`・`🙋 <作業名>`・`🙋🛑 <作業名>`・`✋ <何を>`・`✋✅ <何を>`。
