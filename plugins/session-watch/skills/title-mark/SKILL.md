# 窓の題の目印

題の形と返事の札・締めの正本は核（plugin `core` が起動時に差し込む `plugins/core/核.md`）。ここには核に無い細目だけを置く。手で回す点検（skill `watch-log`）がこの決まりで拾う。

## 種類＝オーナーが相手の窓か

- `🙋`＝オーナーと話す窓（AI が立てた親窓を含む）／`🤖`＝別の窓へ返す窓。誰が立てたか（`parent_session_id`・`origin`）では決めない。
- 種類の元は、窓の最初の頼みの文に書いた返し先だけ: `返し先=オーナー` → `🙋`／`返し先=session_…` か `（親窓 session_… の子）` → `🤖`／どれも無い → 窓が自分で決める（点検は種類の食い違いを拾わない）。
- 役は 親・書く・レビュー・調べ・手 の 5 つだけ。題に役の印は付けない（作業名に書く）。手の窓だけ作業名を `手: <何を>` にする。

## 状態

| 印 | 付ける | 外す |
|---|---|---|
| `❓` | オーナーへの問い（選択肢の画面）を出す前。子の窓も自分で直に問う | 答えが返った時 |
| `⏳` | 手の窓（`🙋⏳ 手: <何を>`）。目的・手順（貼る文は全部）・済んだ目印・済んだ後をその窓に書く | 済んで頼んだ窓へ返す時 |
| `✅` | `🤖` の窓が `AI の残り: なし` で締めるターン | また起こされた時 |
| 無し | 上のどれでもない | — |

- `🙋` の窓に `✅` は付けない。
- 最初の返事の前に付ける。クラウドの窓でまだ種類の印が無い間は、UserPromptSubmit の hook（`session_watch.py --remind`）が頼みのたびに隣へ知らせる（止めない）。返し先が別の窓の子窓には知らせない（立てた親が `create_session` の title で付ける）。
- 付け替えは窓自身が `set_session_title` でする（自分の session id と今の題は `get_session` を session_id を省いて読む）。題の例: `🤖 <作業名>`・`🤖❓ <作業名>`・`🤖✅ <作業名>`・`🙋 <作業名>`・`🙋⏳ 手: <何を>`。
