# 窓の題の目印

題の形と返事の札・締めの正本は核（plugin `core` が起動時に差し込む `plugins/core/核.md`）。ここには核に無い細目だけを置く。手で回す点検（skill `watch-log`）がこの決まりで拾う。題を付ける口（`set_session_title`）と窓を立てる口（`create_session` の title・手の窓の頼みの 4 欄）は、guard の outbound が出す前に同じ正本（`session_watch.py` の `title_shape`）で照らし、崩れていれば AI だけを止める。

## 種類＝オーナーが相手の窓か

- `🙋`＝オーナーと話す窓（AI が立てた親窓と手の窓を含む）／`🤖`＝別の窓へ返す窓。誰が立てたかだけでは決めない（立てた記録＝頼みの行の `origin`・get_session の `parent_session_id` は、次の段で別の窓を指す返し先を数えるかの照らしにだけ使う）。
- 種類の決め方は 2 段: まず手の窓（作業名が `手:` で始まる窓）は返し先によらず `🙋`（相手はオーナー）。それ以外は窓の最初の頼みの文に書いた返し先だけで決める: `返し先=オーナー` → `🙋`／`返し先=session_…` か `（親窓 session_… の子）` → `🤖`（別の窓を指す返し先は手で書いた写しなので、頼みの行の記録が人の打った物でない時（行がまだ無い最初の知らせでは get_session の `parent_session_id`＝別の窓が立てた記録が在る時）＝別の窓や仕組みから来た頼みの時だけ数える。オーナーが引き継ぎの文を貼った窓は `🤖` にしない）／どれも無い → 窓が自分で決める（点検は種類の食い違いを拾わない）。この文は見張りの正本（`session_watch.py` の `KIND_RULE`・決め方は `window_kind`）と同じ文で、試験が一致を照らす。
- 役（何をする窓か）は作業名に書き、題に役の印は付けない。役の決まった一覧は無い（相談だけ・見張りだけの窓も、そのまま作業名に書く）。手の窓だけ作業名を `手: <何を>` にする。

## 状態

| 印 | 付ける | 外す |
|---|---|---|
| `❓` | オーナーへの問い（選択肢の画面か、チャットで聞く開いた問い）を出す前。子の窓も自分で直に問う | 答えが返った時 |
| `⏳` | 手の窓（`🙋⏳ 手: <何を>`）。目的・手順（貼る文は全部）・済んだ目印・済んだ後をその窓に書く | 済んで頼んだ窓へ返す時 |
| `✅` | `🤖` の窓が `✅終わった`（核 §7 の「終わった」）で報告するターン。`🛑止まった`・一部で締める時は付けない | また起こされた時 |
| 無し | 上のどれでもない | — |

- `🙋` の窓に `✅` は付けない。`✅` は「AI の手が尽きた」でなく「終わった」の印（止まった・一部・続けられないで AI の手が無くなっても付けない）。
- 手の窓を頼んだ窓の「あなたがやること」は手の窓の URL だけ（手順は手の窓へ）。手順を直に書くと、次の頼みの時に同じ hook が知らせる（細目 §4・止めない）。
- 最初の返事の前に付ける。クラウドの窓でまだ種類の印が無い間は、UserPromptSubmit の hook（`session_watch.py --remind`）が頼みのたびに隣へ知らせる（止めない）。返し先が別の窓の子窓には、親が `create_session` の title で付けた題を付け直すよう知らせる（親が付けた題は会話ログに載らず、返事の見張りが照らせない）。
- 題の印が崩れたまま返事を締めると、Stop の hook（`session_watch.py --stop`）が見つけ、次の頼みの時に隣へ知らせる（差し戻さない・返事は書き直さない）。クラウドの窓で題が会話ログに一度も無い時も知らせる（`get_session` で今の題を読み、`set_session_title` で付け直す）。
- 付け替えは窓自身が `set_session_title` でする（自分の session id と今の題は `get_session` を session_id を省いて読む）。題の例: `🤖 <作業名>`・`🤖❓ <作業名>`・`🤖✅ <作業名>`・`🙋 <作業名>`・`🙋⏳ 手: <何を>`。
