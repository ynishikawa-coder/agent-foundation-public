# 窓の題の目印

題の形・印の意味・返事の 4 札と締めの 1 行の正本は核（plugin `core` が起動時に差し込む `plugins/core/核.md` §4・§5）。ここには核に無い細目（種類の決め方・印を付け替える時・引き継ぎの 1 行目）だけを置く。会話ログの見張り（skill `watch-log`）がこの決まりで拾う。

## 種類＝オーナーが相手の窓か（この窓が誰に返すか）

- `🙋`＝返し先がオーナー（オーナーが話しかける窓）／`🤖`＝返し先が別の窓か仕組み。
- **誰が立てたかでは決めない。** 親の窓の有無（`parent_session_id`）・立てた口（`origin`）は種類の元にしない。AI が立てた窓でも、オーナーへ返すなら `🙋`。
- **種類の元は、窓の最初の頼みの文に書いた返し先だけ**（見張りもここだけを読む）:
  - `返し先=オーナー` → `🙋`
  - `返し先=session_…`（窓の id）→ `🤖`
  - `（親窓 session_… の子）` → `🤖`（子は親へ返す）
  - どれも無い → 窓が自分で返し先を見て決める（見張りは種類の食い違いを拾わない）
- **引き継ぎ**: 重くなった窓が後継の窓へ移る時、後継は前の窓の返し先を継ぐ。後継を立てる頼みの 1 行目を次の形にする（オーナーへ返す窓の後継は `🙋` のまま）:

  ```
  あなたは後継の窓です（前の窓 <前の窓の session id>・返し先=<オーナー|返し先の窓の session id>）。
  ```

## 状態を付け替える時

| 印 | 付ける | 外す |
|---|---|---|
| `❓` | オーナーへの問い（選択肢の画面）を出す前 | 答えが返った時（返らずに畳まれた問いは残す） |
| `⏳` | 人にしか打てない手を細目 §4「オーナーに手を頼む」の型（何のため／手順／済んだ目印／済んだ後）で渡して締める前（型が無いと Stop の見張りが `wait` で止める） | 待った作業が済んだ時 |
| `✅` | `🤖` の窓が `この窓: 残りなし` で締めるターン | また起こされた時 |

- `🙋` の窓に `✅` は付けない（閉じるかはオーナーが決める）。同じ理由で `🙋` の窓は締めにアーカイブの申し出（` → アーカイブしてよい`）を足さない。
- 付け替えは窓自身が `set_session_title` でする（自分の session id と今の題は `get_session` を session_id を省いて読む）。題の例: `🤖 <作業名>`・`🤖❓ <作業名>`・`🤖✅ <作業名>`・`🙋 <作業名>`・`🙋⏳ <作業名>`。
