## 1. 意図
〔その仕組み・作業が本来何のために在るか（誰の・何を・どうしたいか）。意図そのものが誤っていないかもここで疑う〕

## 2. 課題
〔意図と起きた事象のずれ。起きた事実（何が・どこで・誰が何に困ったか）と、意図に照らして何がどれだけずれたか。「なぜ」は書かない（次の欄へ）。渡された 1 件の症状を課題の幅にしない〕

## 3. 原因と同じ原因の他の問題
**原因**: 〔仕組みや設計が悪い前提で 1 文。決まりの無理・無駄・重複／決まりの聞かせ方／仕組み（repo の構造・道具）／他の文脈が混じって解釈が分かれる所 のどれか〕
**同じ原因の他の問題**（原因の 1 文だけを渡した読むだけの助手が返した一覧をそのまま・場所つき）:
- 〔`場所` — 何が起きている・起きうるか〕

## 4. 解決（足す物・畳む物・注入の試験と残る穴）
**足す物**: 〔誤りが入れない形のどれにするか（写す工程を無くす／誤った物が入れない・既定で止まる／正しい道だけが証明付きで出す／防げない物は名指しで人の関所へ）と、どこをどう変えるか〕
**行き先**（3 欄の原因と一覧の全部・原因の台帳の行と同じ。直す窓〔URL〕／直した〔所在〕／直さない〔オーナーが決めた理由〕）:
- 〔原因か一覧の 1 行〕 — 〔行き先〕
**畳む物**（行頭の [同梱]＝この patch で畳む・既定／[後片付け]＝触ってよい path の外にある物だけ・原因の台帳の行にして直す窓を書く）:
- 〔[同梱] か [後片付け]〕 〔`畳む物の path や名前`〕 — 〔構造を変えるとなぜ要らなくなるか〕
**注入の試験**: 〔直す誤りの類を作り物でわざと入れて仕組みが拒む試験の名（`tests/…::test_…`）と回す口（CI・物差し）。書けないなら根治と書かず、一時しのぎの 3 つ（理由・また起きる見込み・恒久の直し）を書く〕
**残る穴**（1 行ずつ 無し／塞いだ〔どこで〕／残る〔理由。原因の台帳の行にする〕）:
- 手で写す所: 〔…〕
- 選べる値の外が入る所: 〔…〕
- 知らない値・欠けた材料・表せない決まりで黙って進む所: 〔…〕
- 正しい道を通らずに出る所: 〔…〕
- 申告で済む確かめ: 〔…〕

## 5. 未来
〔直した後、1 欄の意図が果たされ、同じ課題と 3 欄の他の問題が起きない姿。何が無くなり何が変わるか（作業する者の手順・オーナーの手・決まりの量）。試験の名を並べる欄ではない〕
