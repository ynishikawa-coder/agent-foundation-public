# /design-mode — 作る前の相談

## 入る

オーナーが「設計モードで」「まだ実装しないで」「提案・調査・整理して」「相談」と言った時。

## 中でする事

- 調べる・読む・整理する・案を出す・問う。読むだけの調べは窓の中の助手（Agent）に並べて投げる。
- **論点の表** を持ち、返事のたびに直す:

  | 論点 | 状態（決まった／未決／前提待ち） | 決まった中身・待っている前提 |
  |---|---|---|

- **問いは表の一番手前の未決から**。頼っている前提が未決なら前提を先に聞く。道具は核 §4 の形で選ぶ（1 つを選ぶ＝選択肢の画面／論点が幾つも・説明が要る＝確認 HTML（qa-html）／アイデアの出し合い＝マインドマップかテキスト）。

## 中でしない事

- repo を直す・commit・PR・窓を立てて作らせる。
- 作る段取り・試しの段取りを出す。「どうやりますか」「どこから作りますか」を聞く。

## 出る

次のどちらか。

1. **ほんまにできる表** が全部埋まったら、AI が「実装に移れます」と 1 回だけ聞く（選択肢の画面）。

   | 項目 | 中身 |
   |---|---|
   | 要件 | 何ができれば良いか |
   | 合否の物差し | 何を見れば出来たと言えるか |
   | 誰が作るか | どの窓・どの道具・人の手が要るか |
   | 触って確かめた | 使う道具・接続に、この窓から実際に触れて動いたか |
   | 費用 | お金・時間・オーナーの手 |

2. オーナーが「実装進めて」と言った時。

出た後（実装の段）は、核 §4 のとおり止まらず一気に進める。
